# スクショツール (screenshot-tool)

Windows 向けの、常駐型スクリーンショット&注釈ツールです。Rust と [egui](https://github.com/emilk/egui) で作っています。

タスクトレイに常駐し、ホットキーで撮影、そのまま注釈を付けて、ファイル保存とクリップボードへのコピーを同時に行います。

## 機能

**撮影**
- グローバルホットキー(既定 `Ctrl+Shift+S`)またはトレイのクリックで撮影
- ドラッグで範囲選択(`Enter` で全画面、右クリック / `Esc` でキャンセル)
- 範囲選択中のルーペ(円形・拡大・座標と色の表示。`Shift`+ドラッグで位置を移動)
- ウィンドウ自動検出: クリックで、そのウィンドウを前面に出してフォーカスを当て、きれいに撮影
- UI 要素検出(UI Automation): ウィンドウ内のペイン(タブ領域・メイン領域など)単位で撮影
  - 要素キー(既定 `E`)を押している間は、ウィンドウ単位 ⇔ ペイン単位を反転
  - 詳細キー(既定 `D`)を押している間は、最も細かい要素。`D` を押したままホイールで1つずつ大きく/小さく
  - Web ページなど、要素が公開されない画面では、見た目から文字・画像のかたまりを切り出す

**編集**
- ツールは、編集画面の左側に縦一列のアイコンで並ぶ(名前はホバーで表示)
- 選択 / ペン / 蛍光ペン / 直線 / 矢印 / 両矢印 / 曲線矢印 / 四角 / 楕円 / 括弧 / 文字 / 吹き出し / 番号 / モザイク / 切り抜き
- 括弧は 丸 `( )`・角 `[ ]`・波 `{ }` の3種類。曲線矢印は中央のつまみで曲がりを調整
- 番号は 丸/四角 × 塗り/逆(白地に色の枠)の4種類。数字は図形の中心に合わせて描画
- モザイクの強度(ブロックの大きさ)はスライダーで変更でき、選択中のモザイクにも後から効く
- 吹き出しは 角丸・楕円・四角・もくもく の4種類。本体の大きさ、しっぽ、文字の大きさをハンドルで変更
- 描いた図形は、ハンドルで形を変えたり、移動・色変更・削除ができる
- 元に戻す/やり直し(50段階)、拡大縮小(`Ctrl`+ホイール)

**出力**
- 保存形式(PNG / JPEG)、保存先、ファイル名の命名規則、出力倍率、長辺の上限を設定可能
- `Enter` で「保存 + クリップボードにコピー」、`Ctrl+C` でコピーのみ

## 設定

実行ファイルと同じフォルダの `ScreenshotTool.ini` に保存されます(初回起動時に自動作成)。
トレイメニューの「設定...」から画面で変更できます。ホットキーの変更は再起動後に反映されます。

**Windows 起動時の自動起動**を設定できます(現在のユーザーのスタートアップフォルダに、このツール専用のショートカットを1つだけ置きます。管理者権限は不要で、Windows の「スタートアップ アプリ」にも表示されます。オフにするとショートカットを消します)。

## ビルド

Rust(2024 edition 対応の安定版)と Windows が必要です。

```
cargo build --release
```

`target/release/screenshot-tool.exe` ができます。

テストと静的解析:

```
cargo test
cargo clippy --all-targets
```

## 注意

- Windows 専用です(Win32 API と UI Automation を使用)。
- ウィンドウ前面化のために `Alt` キーの押下を送出します。
- Chromium 系ブラウザ・Electron アプリは、ページ内の要素を UI Automation に公開しないことがあります。その場合は「見た目のかたまり」で代替します。
