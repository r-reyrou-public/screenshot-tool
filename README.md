# SnapMark(スナップマーク)

<img src="assets/icon.png" width="96" alt="SnapMark">

Windows 向けの、常駐型スクリーンショット&注釈ツールです。Rust と [egui](https://github.com/emilk/egui) で作っています。

タスクトレイに常駐し、ホットキーで撮影、そのまま注釈を付けて、ファイル保存とクリップボードへのコピーを同時に行います。
アルバムと編集画面は、呼び出されたときだけメモリに展開し、閉じるとすぐに手放します(常駐中は最小限)。
トレイアイコンの左クリックでアルバム、右クリックでメニュー(スクショ・アルバム・設定など)が開きます。

## 使い方(操作方法)

### 1. 起動と常駐
- `snapmark.exe` を実行すると、タスクトレイに常駐します(ウィンドウは出ません)。
- トレイアイコンの **左クリック** でアルバム、**右クリック** でメニュー(スクショを撮る / アルバムを開く / 保存先フォルダを開く / 設定 / 終了)が開きます。
- 新しい版があるときは、トレイアイコンに赤い点が付きます。

### 2. 撮影する
1. ホットキー(既定 `Ctrl+Shift+S`)を押すか、トレイメニューの「スクショを撮る」を選びます。カーソルのあるモニタが静止し、画面いっぱいに伸びる細い十字線が出ます。
2. 撮りたい範囲を、次のどれかで決めます。

| やりたいこと | 操作 |
|---|---|
| 好きな範囲を撮る | 範囲を **ドラッグ**。左上に寸法(幅 x 高さ)が出ます |
| ウィンドウ1枚を撮る | ウィンドウの上で **クリック**(青い枠が出ているウィンドウ)。前面に出してから撮ります。重なっている場合は最前面のウィンドウ |
| ウィンドウ内の区画(ペイン・タブ領域など)を撮る | `E` を **押している間**、緑の枠の区画が選べます。クリックで撮影 |
| もっと細かい要素(ボタン・1つの画像など)を撮る | `D` を **押している間**、最も細かい要素を選びます。**ホイール** を回すと、1つずつ大きく / 小さくなります。クリックで撮影 |
| 画面全体を撮る | `Enter` |
| 縦に長い内容を1枚で撮る(スクロール撮影) | `S` で ON にしてから、範囲かウィンドウを選ぶ(下の「3. スクロール撮影」) |
| キャンセル | 右クリック または `Esc` |

3. 範囲を決めると、編集画面が開きます(次の項目)。

**その他の撮影中の操作**
- **ルーペ**(拡大・座標と色の表示): カーソルの近くに出て、カーソルが近づくと隅から逃げます。`Shift` を押しながらルーペを **ドラッグ** すると、好きな隅・位置に動かせます(位置は保存されます)。
- `W`: 押している間だけ、ウィンドウ検出の ON/OFF を反転します(設定が ON なら、押している間だけ OFF)。
- `E`: 押している間だけ、UI 要素単位の検出の ON/OFF を反転します。
- 上の `W` / `E` / `D` / `Shift` / `Enter` / `S` は、**設定画面で別のキーに変えられます**(「範囲選択中の操作キー」の「押して設定」を押してから、使いたいキーを押します)。
- 画面上部のヒント文には、いま使える操作が、設定したキー名で表示されます。

### 3. スクロール撮影(縦に長い画面を1枚にする)
1. 撮影を始め、範囲選択の画面で `S` を押します(「スクロール撮影 ON」と表示されます。もう一度押すと OFF)。
2. 撮りたい **範囲をドラッグ**、または **ウィンドウ / 区画をクリック** します。
3. あとは自動です。SnapMark が、選んだ範囲の中央にカーソルを置き、ホイールを送りながら何枚も撮って、1枚につなぎます。撮影中は、画面を触らないでください。途中までスクロールされていた画面でも、いったん先頭まで戻してから撮ります。
4. 最後まで行く(これ以上スクロールしない)と、つないだ画像が編集画面で開きます。途中で止めたいときは `Esc` です。

コツ:
- Web ページは、ブラウザ全体のクリックではなく、**ページ部分だけをドラッグ** で選ぶと、固定のタブバーなどを含めずに撮れます。
- 上や下に固定されたヘッダー・ステータスバーは、1回だけ写ります。
- サイドバーなどの動かない部分と並んでいる画面(アプリのウィンドウなど)は、自動でスクロールする場所を探し、**スクロールする部分だけ** を縦につなぎます(サイドバーは含まれません)。
- 動画・広告・自動更新のある画面は、つなぎ目がずれることがあります。高さの上限は約 30000px です。

### 4. 編集画面
撮影すると、編集画面が開きます。左に縦一列のツール、上に色・太さ・操作ボタンが並びます。

| 操作 | 内容 |
|---|---|
| ツールの選択 | 左のアイコンをクリック(名前は、カーソルを乗せると出ます) |
| 色・太さ | 上の色見本をクリック / 太さのスライダー。すでに描いた図形を選んでいるときは、その図形にも効きます |
| 図形を描く | ドラッグ(ツールごとの操作は、画面下のヒントに出ます) |
| 45度刻み・正方形・正円 | `Shift` を押しながらドラッグ(直線・矢印は45度刻み、四角は正方形、楕円は正円) |
| 描いた図形を直す | 「選択」ツールで図形をクリックして選び、**ハンドルをドラッグして形を変更**、本体をドラッグして移動。`Delete`(または `Backspace`)で削除。文字は **ダブルクリック** で編集 |
| 曲線矢印 | 中央の丸いつまみをドラッグして、曲がりを調整 |
| 括弧・番号・吹き出し | 丸 / 角 / 波(括弧)、丸 / 四角 × 塗り / 逆(番号)、角丸 / 楕円 / 四角 / もくもく(吹き出し)を、ツールを選ぶと出る選択肢から切り替え |
| モザイク | 範囲をドラッグ。強度スライダーで、あとから選択中のモザイクの粗さも変えられます |
| 切り抜き | 「切り抜き」ツールで範囲をドラッグし、`Enter` で確定(`Esc` で取りやめ) |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z`(または `Ctrl+Y`)。50段階まで |
| 拡大縮小 | `Ctrl` を押しながらホイール。「100%」で等倍、「全体表示」で画面に収まる大きさ |
| 選択を外す | `Esc`(何も選んでいなければ、編集を破棄) |

**編集の終わり方**
- `Enter` または「完了」: 画像を保存し、同時にクリップボードにもコピーします。
- `Ctrl+C` または「コピー」: クリップボードへのコピーだけ(保存はしません)。
- `Esc` または「破棄」: 保存せずに閉じます。
- 保存先・ファイル形式・ファイル名は設定画面で決めます(下の「設定」)。

### 5. アルバム(撮った画像を見る・直す)
- 開き方: トレイアイコンの **左クリック**、またはメニューの「アルバムを開く」。保存先フォルダの画像(PNG / JPEG)がサムネイルで並びます。
- **クリック** で選択、**ダブルクリック**(または `Enter`)で大きく表示、`←` `→` で前後の画像へ。`Esc` で戻る / 閉じる。
- 選んだ画像に対して、**コピー**(`Ctrl+C`)、**編集**(編集画面で開き、完了すると **新しいファイル** として保存。元のファイルは変わりません)、**削除**(確認が出ます。元に戻せません。`Delete` でも可)。
- 範囲選択の画面が出ている間にトレイからアルバム・保存フォルダを開くと、範囲選択をやめて開きます。編集画面の間にアルバムを開いたときは、編集内容をそのまま残したまま開き、アルバムを閉じる(`Esc` / 「閉じる」)と元の編集画面に戻ります(このとき、アルバムからの「編集」は使えません)。保存フォルダは編集中でも開けます。
- 並びの新しい順 / 古い順の切り替え、再読み込み、フォルダを開く、ができます。サムネイルは120枚ずつ読み込み、「さらに表示」で追加します。

### 6. 設定画面
トレイメニューの「設定...」(または `snapmark.exe --settings`)で開きます。変更して「保存」を押すと反映されます(再起動は不要)。

| 項目 | 説明 |
|---|---|
| ホットキー | 「キーを押して設定」を押してから、使いたい組み合わせを押します(例: `Ctrl+Shift+A`)。`Ctrl` / `Alt` / `Shift` のどれかを含めてください(F1〜F24 は単独で可)。他のアプリと重複して登録できないときは、理由が表示されます |
| 起動 | Windows の起動時に自動で起動する(スタートアップにショートカットを置きます) |
| 更新 | 数日に1回、新しい版を確認する |
| 保存先フォルダ | 入力、「貼り付け」、「参照...」で指定 |
| ファイル形式 / JPEG品質 | PNG か JPEG。JPEG のときは品質(1〜100) |
| 命名規則 | 拡張子なしのファイル名。`%Y`年 `%m`月 `%d`日 `%H`時 `%M`分 `%S`秒(既定 `Screenshot_%Y%m%d_%H%M%S`)。例が下に表示されます |
| ウィンドウ自動検出 | ウィンドウ単位 / UI 要素単位の検出の ON/OFF、「かたまりの大きさ」(Web ページなど要素が公開されない画面での切り出しの細かさ) |
| 範囲選択中の操作キー | ウィンドウ検出・UI要素検出・最も細かい要素・ルーペ移動・全画面・スクロール撮影の各キー |
| ルーペ | 表示する隅(またはオフ)、倍率、大きさ、位置の調整 |
| 出力倍率 / 長辺の上限 | 保存・コピーする画像の拡大縮小(10〜200%)と、長辺の最大ピクセル数 |

設定は、実行ファイルと同じフォルダの `SnapMark.ini` に保存されます。

### 7. 終了とアップデート
- 終了: トレイメニューの「終了」。
- アップデート: 新しい版があると、トレイメニューと設定画面に案内が出ます。「ダウンロードページを開く」から、新しい `snapmark.exe` を入手し、起動中のものを終了してから置き換えてください(自動更新はしません)。

## 機能

**撮影**
- グローバルホットキー(既定 `Ctrl+Shift+S`)またはトレイメニューの「スクショを撮る」で撮影
- 撮影中のカーソルは、画面いっぱいに伸びる細い十字線(矢印なし)。範囲・ウィンドウ・要素は、半透明の塗りなしの枠線で囲んで示す
- ドラッグで範囲選択(`Enter` で全画面、右クリック / `Esc` でキャンセル)
- 範囲選択中のルーペ(円形・拡大・座標と色の表示。`Shift`+ドラッグで位置を移動)
- ウィンドウ自動検出: クリックで、そのウィンドウを前面に出してフォーカスを当て、きれいに撮影
  - UWP アプリなどの二重検出を避けて判定。Windows 11 のウィンドウは、角丸の外側を透明にして撮影(JPEG は背景色)
- UI 要素検出(UI Automation): ウィンドウ内のペイン(タブ領域・メイン領域など)単位で撮影
  - 要素キー(既定 `E`)を押している間は、ウィンドウ単位 ⇔ ペイン単位を反転
  - 詳細キー(既定 `D`)を押している間は、最も細かい要素。`D` を押したままホイールで1つずつ大きく/小さく
  - Web ページなど、要素が公開されない画面では、見た目から文字・画像のかたまりを切り出す
- スクロール撮影: 範囲選択中に `S`(既定)で ON にしてから、範囲かウィンドウ(要素)を選ぶと、自動でホイールを送りながら撮り、重なりを探して縦長の1枚につなぐ
  - 上部・下部に固定されたヘッダーやステータスバーは1回だけ写す。スクロールバーの部分は、つなぎ目の判定から除く。撮影中は `Esc` で中止
  - 高さの上限は約 30000px。内容が変化するページ(動画・自動更新など)では、つなぎ目がずれることがあります
- 範囲選択中の操作キー(ウィンドウ検出 `W`、要素検出 `E`、詳細 `D`、ルーペ移動 `Shift`、全画面 `Enter`、スクロール撮影 `S`)は、すべて設定画面で変更可能。画面下のヒントも設定したキー名で表示

**編集**
- ツールは、編集画面の左側に縦一列のアイコンで並ぶ(名前はホバーで表示)
- 選択 / ペン / 蛍光ペン / 直線 / 矢印 / 両矢印 / 曲線矢印 / 四角 / 楕円 / 括弧 / 文字 / 吹き出し / 番号 / モザイク / 切り抜き
- 括弧は 丸 `( )`・角 `[ ]`・波 `{ }` の3種類。曲線矢印は中央のつまみで曲がりを調整
- 番号は 丸/四角 × 塗り/逆(白地に色の枠)の4種類。数字は図形の中心に合わせて描画
- モザイクの強度(ブロックの大きさ)はスライダーで変更でき、選択中のモザイクにも後から効く
- 吹き出しは 角丸・楕円・四角・もくもく の4種類。本体の大きさ、しっぽ、文字の大きさをハンドルで変更
- 描いた図形は、ハンドルで形を変えたり、移動・色変更・削除ができる
- 元に戻す/やり直し(50段階)、拡大縮小(`Ctrl`+ホイール)

**アルバム**
- トレイアイコンの左クリック、またはトレイメニューの「アルバムを開く」(`snapmark.exe --album` で起動して開くことも可能。`--settings` は設定画面)で、保存先フォルダの画像(PNG/JPEG)をサムネイルで一覧
- クリックで選択、ダブルクリック(または `Enter`)で大きく表示、`←` `→` で前後の画像へ
- 選んだ画像を「コピー」(`Ctrl+C`)、「編集」(編集画面で開き、完了すると新しいファイルとして保存。元のファイルは変わりません)、「削除」(確認あり。元に戻せません)
- 新しい順 / 古い順の切り替え、再読み込み、フォルダを開く。サムネイルは120枚ずつ読み込み(「さらに表示」で追加)

**出力**
- 保存形式(PNG / JPEG)、保存先、ファイル名の命名規則、出力倍率、長辺の上限を設定可能
- `Enter` で「保存 + クリップボードにコピー」、`Ctrl+C` でコピーのみ

## 設定

実行ファイルと同じフォルダの `SnapMark.ini` に保存されます(初回起動時に自動作成)。
トレイメニューの「設定...」から画面で変更できます。
ホットキーは「キーを押して設定」で、押した組み合わせをそのまま登録できます(保存した時点で再起動なしに反映)。
他のアプリと重複するなどで登録できない場合も、アプリは終了せず、設定画面で理由を表示します。
範囲選択中の操作キーも、同様に「押して設定」で変更できます。

**Windows 起動時の自動起動**を設定できます(現在のユーザーのスタートアップフォルダに、このツール専用のショートカットを1つだけ置きます。管理者権限は不要で、Windows の「スタートアップ アプリ」にも表示されます。オフにするとショートカットを消します)。

## アップデートの確認

数日に1回(3日ごと)、撮影や設定を開いたときに、バックグラウンドで GitHub の最新リリース(pre-release は対象外)を問い合わせ、新しい版があれば、
タスクトレイのアイコンに赤い点のバッジを付け、トレイメニューと設定画面で案内します
(「ダウンロードページを開く」でこのリポジトリのリリースページが開きます)。自動ダウンロード・自動更新はしません。
通信は OS 標準の WinHTTP で、版番号を読むだけです。設定画面の「数日に1回、新しい版を確認する」で切れます。

## ダウンロード

[Releases](https://github.com/r-reyrou-public/screenshot-tool/releases) から `snapmark.exe` を入手できます。
インストール不要で、好きなフォルダに置いて実行します(設定の INI は exe と同じフォルダに作られます)。

## ビルド方法

### 必要なもの

- Windows 10 / 11
- Rust(2024 edition に対応した最近の安定版)— [rustup](https://rustup.rs/) で入れられます
- MSVC ビルドツール(Visual Studio Build Tools の「C++ によるデスクトップ開発」)と Windows SDK
  - exe にアイコンとバージョン情報を埋め込むために、Windows SDK の `rc.exe` を使います
    (見つからない場合も警告だけでビルドは通りますが、アイコンは付きません)

### 手順

```
git clone https://github.com/r-reyrou-public/screenshot-tool.git
cd screenshot-tool
cargo build --release
```

`target/release/snapmark.exe` ができます。開発中の実行は `cargo run` でできます。

### テストと静的解析

```
cargo test
cargo clippy --all-targets
cargo test -- --ignored   # 実際にスタートアップフォルダや GitHub へ触る確認(手元でのみ実行)
```

## 注意

- Windows 専用です(Win32 API と UI Automation を使用)。
- ウィンドウ前面化のために `Alt` キーの押下を送出します。
- Chromium 系ブラウザ・Electron アプリは、ページ内の要素を UI Automation に公開しないことがあります。その場合は「見た目のかたまり」で代替します。
